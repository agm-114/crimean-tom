# Portable field classification

This is the current Phase 1 read contract, not a promise of write support.

| Field family | Classification | Current meaning |
| --- | --- | --- |
| Campaign tag identity | exact | Stable external identity when the authored mission supplies a campaign tag. |
| Game unique ID identity | exact, session-scoped | Surrogate valid only for the loaded scene; invalidated on reload. |
| Unit/catalog type, folder, variant, loadout, nation | exact | Runtime strings with winning-file provenance where catalog-backed. |
| Task-force membership | exact | Sorted stable unit IDs observed from the live task force. |
| Latitude, longitude, altitude, heading, speed | quantized | Exact serialization of the native floating-point value; physical precision is limited by the game representation. |
| Current state/order name and target | exact | Native enum/type name plus the stable ID of an exposed target reference. |
| Waypoint chains | exact or quantized | Ordered native routes include position/height, reachability, course/turn flags, timing, relative parent, autogenerated state, and engagement parameters. |
| Fuel and damage totals | quantized | Native floating-point observations. |
| Fuel and damage fractions | derived | Computed from observed native totals with explicit null/zero handling. |
| Ammunition/store counts | exact observations, not universally portable | Unsupported stores remain absent rather than inferred. A native torpedo round trip restored the fired Mk-37 count but changed Scamp's unrelated Mk-16 count from 15 to 9. |
| Hosted aircraft capacity/assignment | exact for exposed builder/flight-deck collections | Tactical lifecycle details remain incomplete. |
| Active weapon identity, target links, stage | exact for exposed native references | Blind-fire missile, torpedo, and bomb identity/type/platform/stage survived native round trips. Targeted guidance, final damage equivalence, and portable reconstruction remain unproven. |
| Active weapon kinematics/range fractions | quantized or derived | Native floats plus explicitly derived fractions. |
| Sensor/contact tracks | player-authorized projection | The player taskforce plotting table supplies track number, detected/estimated position, uncertainty, classification, detected side, relationship, dormant/visual state, and deduplicated current sensor provenance. True target references and positions are deliberately absent. |
| Player alerts/intelligence | exact for bounded native event-log entries | Recent player-visible entries include scenario time, priority, text, and exposed object links; totals and truncation are explicit. Developer/omniscient diagnostic logs are excluded. |
| Spatial envelope diagnostics | diagnostic, nonportable | Reports floating-origin thresholds, object extents, camera offset, and loaded terrain distribution. It measures native session capacity but is excluded from the canonical world hash and cannot reconstruct terrain or physics state. |
| Repair/rearm maintenance state | exact for native Task Force Manager rows | Exposes native damage summary, repair eligibility/cost/status, repaired/rearmed badges, and ammunition summaries. An externally damaged fixture still needs a prior native damage-state section before repair can become eligible. |
| Reinforcement availability | exact | The versioned external projection generates the native allowed roster and validation enforces type, variant, quantity, budget, and port capacity. |
