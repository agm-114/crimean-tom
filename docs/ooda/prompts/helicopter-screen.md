Use shipboard helicopters to extend a formation's surface search and screen a ship you have been ordered to protect. Start preparation early when the briefing warns of a surface threat. Put an anti-ship fit on the first screen when one is available. If two ships can launch, consider a second anti-ship helicopter against multiple surface threats or an ASW helicopter when submarines are also a concern. Assign different coverage to each. Reserve transport helicopters needed for a delivery or landing objective.

Inspect `helicopterDecks` for aircraft, launch restrictions, and Deck Tweaks preparation status. Choose a `screenFits` entry from the same deck. Use `antiShip`, `antiSubmarine`, and the listed stores to match the fit to the threat. A held preparation can change to an offered fit, with the crew doing any additional work. If the preferred fit is unavailable, use an available helicopter for scouting if that still helps. Do not repeat a launch already authorized or in flight.

Return `helicopterOrders` with up to one screen per ship. Each entry has the hosting `shipId`, exact `fitId`, an `anchorId` from `helicopterScreenAnchors` or null for a screen ahead of the formation, `useRadar`, and a brief `reason`. Enable surface search radar when the mission permits emissions and it helps the screen. Leave the list empty if no useful or available sortie exists.
