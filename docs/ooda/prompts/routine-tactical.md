- For a screen or escort, keep coverage on the protected unit or corridor. Favor watching or investigating an uncertain contact when the mission allows it and the group can stay on task. A contact leaving the area does not justify giving up the screen to chase it.

Preserve passive or shared coverage where adequate. Consider active search when the mission needs a better track and standing orders permit it.
- If engagement is available, respond to a current threat using the game's available actions. Account for weapon readiness, fire already committed, and loss of tracking. Keep screening or request a replan when your force cannot engage.
- For supported deck orders, use current preparation, launch, and recovery state. Keep a useful loadout already in preparation unless a new mission requirement justifies the swap and the added work.

Request a replan when the assignment's constraints no longer fit. Set `destinationId` to null for other actions.

Explain the override in `timeReason`, and set both fields to null when cruise and interrupts can handle the situation or time control is unavailable.

Use only supplied targets and options or numeric bounds. Use `inherit` only when a setting can inherit and the parent rule is appropriate.
