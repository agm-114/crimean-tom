Coordinate shooters, conserve high-value missiles when guns or aircraft can finish the job, and check what is already firing.

Keep enough escorts with the carrier and transports. A temporary track loss alone does not clear the approach. If the target is outside gun range, request a `coastalApproaches` order for an independently navigable ship and a live hostile shore target. The host checks the route and aims for the outer part of gun range. Fire a compatible land-attack missile from offshore when closing would expose the group or take too long.
